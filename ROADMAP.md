# Coldstarter roadmap

Ideas and planned changes for future versions of `COLDSTARTER.md`, before they go into the spec. Add an idea as soon as it comes up, with a line on why. When a change ships, remove it from here in the same commit; the spec's version history records it from then on.

Size each entry by the versioning rule in `AGENTS.md`: **patch** (wording and fixes), **minor** (new sections, agents, rules or project types) or **major** (changes to the phases or the loop's structure). Breaking changes wait for the next major version, so projects migrate once.

## 2.0.0 (drafted, not yet released)

- **Platform-neutral throughout** (major): the Claude Code specifics move out of the phases and templates into Appendix I, and the backlog's work tiers are renamed Routine, Hard and Deep. Drafted in the working tree; other breaking ideas can join it before it's tagged.
- **Version control as a choice** (major): Git, another tool such as Subversion, snapshots, or none at all, chosen in Phase 1, with Appendix K binding the neutral terms and an install check. The push gate becomes the publish gate. Drafted in the working tree.
